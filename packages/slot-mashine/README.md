# @ralphschuler/slot-mashine

Simulates weighted reels, horizontal and diagonal payouts, credits and free spins.

## Learn the concept

[English](https://nyphon.de/.ts-libs/en/modules/slot-mashine/) · [Deutsch](https://nyphon.de/.ts-libs/de/modules/slot-mashine/)

## Run the verified example

From the repository root:

```sh
yarn tsx packages/slot-mashine/examples/basic.ts
yarn workspace @ralphschuler/slot-mashine test
```

The package exports ESM from dist/index.js and declarations from dist/index.d.ts. Run yarn build before importing workspace packages.

## Scope and next steps

The engine is an educational deterministic simulation. UI, real-money accounting and regulatory requirements are outside its contract.

See [the completion matrix](../../documentation/completion-matrix.md) and [experiment standards](../../documentation/experiment-standards.md).
