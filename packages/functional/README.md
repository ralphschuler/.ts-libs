# @ralphschuler/functional

Exports tagged Option and Result values, guards and pattern matching.

## Learn the concept

[English](https://nyphon.de/.ts-libs/en/modules/functional/) · [Deutsch](https://nyphon.de/.ts-libs/de/modules/functional/)

## Run the verified example

From the repository root:

```sh
yarn tsx packages/functional/examples/basic.ts
yarn workspace @ralphschuler/functional test
```

The package exports ESM from dist/index.js and declarations from dist/index.d.ts. Run yarn build before importing workspace packages.

## Scope and next steps

Wrappers are shallowly frozen; error capture and higher-order combinators are explicit extensions.
